# AI Resume & Job Description Matcher

An AI-powered Python application that analyzes a resume against a job description and identifies matching skills, missing skills, and overall job compatibility.

## Features

- Resume and job description text analysis
- Skill matching
- Missing skill detection
- Skill-based match score
- TF-IDF text similarity
- Cosine similarity
- Combined resume match score
- Skill recommendations

## Technologies Used

- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Git
- GitHub

## How It Works

1. Enter the resume text.
2. Enter the job description.
3. The application identifies matching skills.
4. It identifies skills missing from the resume.
5. TF-IDF and cosine similarity are used to calculate text similarity.
6. A combined match score is generated.
7. Missing skills are recommended for learning.
